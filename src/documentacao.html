API do FunilPro

Referência pública dos endpoints do FunilPro — um mini CRM de funil de vendas. Use esta API para gerenciar leads, registrar movimentações no funil e obter relatórios e análises.

Visão geral

URL base

https://qsecahzfqrqdgszuqvbn.supabase.co/functions/v1

Autenticação

Todas as chamadas exigem o cabeçalho x-api-key com a sua chave da API. Endpoints de sessão também aceitam Authorization: Bearer <token>.

# em toda requisição
x-api-key: sua-api-key

Formato das respostas

Sucesso

{
  "dados": [ ... ],
  "total": 13
}

Erro

{
  "erro": "mensagem",
  "codigo": 400
}

Autenticação

POST/auth/registrar

Cria um novo usuário e retorna o token de sessão.

CampoTipoDescrição
nomestringObrigatório.
emailstringObrigatório, único.
senhastringObrigatório, mín. 6 caracteres.
# resposta
{ "dados": { "usuario": {...}, "token": "eyJ..." } }
POST/auth/login

Autentica com email e senha. Retorna o usuário e um token JWT (validade 8h).

GET/auth/me

Retorna o usuário logado. Requer Authorization: Bearer <token>.

Leads

GET/leads

Lista todos os leads ativos, dos mais recentes para os mais antigos.

Parâmetro (query)Descrição
estagioFiltra por estágio (ver referência).
valor_minimoApenas leads com valor ≥ ao informado.
responsavelFiltra pelo nome do responsável.
# exemplo
curl "https://qsecahzfqrqdgszuqvbn.supabase.co/functions/v1/leads?estagio=proposta&valor_minimo=5000" \
  -H "x-api-key: sua-api-key"
POST/leads

Cria um lead. Campo obrigatório: nome.

{
  "nome": "Fulano de Tal",
  "email": "fulano@empresa.com",
  "empresa": "Empresa X",
  "valor": 5000,
  "estagio": "novo",
  "temperatura": "hot"
}
PUT/leads/:id

Atualiza os campos informados de um lead.

DELETE/leads/:id

Remoção lógica (soft delete) — marca excluido = true.

Mudança de estágio

POST/webhook-estagio

Move um lead de estágio, registra a movimentação no histórico de atividades e envia um e-mail de notificação sobre a alteração no pipeline.

CampoDescrição
lead_idObrigatório. ID do lead.
estagio_novoObrigatório. Estágio de destino.
descricaoOpcional. Texto da atividade.

Relatórios

GET/resumo-pipeline

Indicadores do funil: total e valor por estágio, taxa de conversão geral, ticket médio dos fechados, velocidade do funil (tempo médio entre estágios) e top leads em negociação.

GET/relatorio-parados

Leads sem atividade recente (não fechados). Parâmetro dias (padrão 7). Cada lead vem com dias_parado.

Análise por IA

POST/analise-ia

Gera um diagnóstico do funil com IA (Claude), com pontos de atenção e ações recomendadas. O corpo pode ser vazio ({}).

# resposta
{ "dados": { "analise": "...", "modelo": "claude-sonnet-4-6" } }
