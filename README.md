# FunilPRO

Projeto FunilPRO.

## Estrutura

```
FunilPRO/
├── src/          # Código-fonte
├── docs/         # Documentação
├── .env          # Credenciais (NÃO versionado)
├── .env.example  # Modelo de variáveis de ambiente
└── .gitignore
```

## Configuração

1. Copie `.env.example` para `.env`
2. Preencha com suas credenciais do Supabase

## Banco de dados

Supabase. Configure `SUPABASE_URL`, `SUPABASE_PUBLISHABLE_KEY` e `SUPABASE_SECRET_KEY` no `.env`.
